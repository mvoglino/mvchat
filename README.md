# mvchat

Piattaforma erogata da MVitalia per campagne WhatsApp con assistente AI orientato all'obiettivo, per attività di qualsiasi settore (palestre, hotel, centri benessere, studi, negozi…), singole o riunite in gruppi. Primo cliente: FitActive.

- **Installazione su Aruba:** [docs/INSTALLAZIONE-ARUBA.md](docs/INSTALLAZIONE-ARUBA.md)
- **Pacchetto pronto:** scheda *Actions* → ultima esecuzione verde → *Artifacts*
- **Tecnologia:** .NET 10 LTS (ASP.NET Core), MySQL / MariaDB
